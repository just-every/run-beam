# Fonts

Lexend is self-hosted under the SIL Open Font License 1.1 in
`lexend/LICENSE.txt` (upstream: https://github.com/googlefonts/lexend). Lexend
was designed for reading proficiency, which suits lesson text. The single
variable WOFF2 file covers weights 100–900 for Latin text.

The root document and Beam's pages link `/fonts/fonts.css`; `public/rer-theme.css`
declares the same face for the shared installer, sign-in and `/setup` frames.
No page loads fonts from another origin.
